# AGM Manual End-to-End Test Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**AGM-MANUAL-E2E-01** When a manual AGM scenario is run, the system shall identify required host dependencies and preserve observable failures.

**AGM-MANUAL-E2E-02** If an interactive dependency cannot be exercised, the system shall report the scenario as unverified rather than successful.
