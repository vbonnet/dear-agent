# YouTube Plugin Manifest Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**DECL-YOUTUBE-01** When a Claude-compatible harness discovers the YouTube plugin, the system shall expose the versioned plugin identity and capabilities.

**DECL-YOUTUBE-02** If the plugin manifest is invalid, the system shall reject plugin discovery.
