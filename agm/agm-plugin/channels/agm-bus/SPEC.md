# AGM Bus Channel Package Configuration Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**DECL-BUS-PKG-01** When the AGM bus channel package is built or tested, the system shall use the versioned TypeScript compiler, dependency, and package scripts.

**DECL-BUS-PKG-02** If package configuration is inconsistent with the lockfile, the system shall fail installation or verification.
