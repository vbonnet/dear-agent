# AGM Documented Hook Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**AGM-DOC-HOOK-01** When a documented AGM hook example is executed, the system shall use supported lifecycle inputs and portable shell behavior.

**AGM-DOC-HOOK-02** If required hook context is absent, the example shall fail explicitly rather than fabricate session state.
