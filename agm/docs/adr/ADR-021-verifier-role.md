# ADR-021: Verifier Role — SUPERSEDED

## Status

**Superseded (2026-05-17)** by
[`docs/adr/ADR-002: VROOM Execution Architecture`](../../../docs/adr/ADR-002-vroom-execution-architecture.md).

## Why

There is **no standing "Verifier" role** in the corrected VROOM architecture.
Verification is a *responsibility of the Secondary* in each task's
Primary/Secondary/Tertiary ownership — not a separate supervisor. This ADR (and
the five-role model it belonged to) was inaccurate and misfiled under `agm/`.
