# AGM Bus Service Installer Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**AGM-BUS-INSTALL-01** When an operator installs the AGM bus service, the system shall render a platform-appropriate service definition with canonical executable paths.

**AGM-BUS-INSTALL-02** If the target service manager is unavailable, the system shall fail without claiming the service was installed.
