# AGM MCP server ADRs

| ADR | Status | Decision |
|---|---|---|
| [001](001-local-control-surface.md) | Accepted | Use a verified local stdio MCP surface over shared AGM operations. |

The former 001-005 documents were retired on 2026-07-17. Their assumptions
about filesystem manifests, a five-second cache, three read-only tools, and a
metadata-only V1 no longer described the executable server. Git history
preserves them for archaeology.
