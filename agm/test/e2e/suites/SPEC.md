# AGM End-to-End Suite Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**AGM-E2E-SUITE-01** When AGM end-to-end suites run, the system shall cover lifecycle, commands, workspaces, state, accessibility, errors, skills, and active harness parity.

**AGM-E2E-SUITE-02** When harness parity is evaluated, the system shall use the same observable command contract for Claude Code, Codex, Antigravity, and OpenCode.
