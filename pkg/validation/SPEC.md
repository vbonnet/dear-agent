# Validation Facade Specification

<!-- Last audited at: 2026-07-09 -->

## EARS Requirements

**VALIDATION-01** When shared validation is imported, the system shall expose the canonical validation package boundary without harness dependencies.

**VALIDATION-02** While validation is invoked from any supported harness and model family, the system shall delegate to the same scoped validators and result contracts.
