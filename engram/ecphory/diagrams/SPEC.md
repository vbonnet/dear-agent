# Ecphory Diagram Rendering Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**ECPHORY-DIAGRAM-01** When Ecphory diagrams are rendered, the system shall generate outputs from the versioned diagram sources.

**ECPHORY-DIAGRAM-02** If the renderer is unavailable or a source is invalid, the system shall fail without replacing valid outputs with incomplete artifacts.
