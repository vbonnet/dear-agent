# AI Tools

Experimental tools for AI-assisted development workflows.

## Tools

### AGM (Agent Gateway Manager)
Session management CLI for Claude Code + tmux workflows (formerly claude-session-manager).
- Go-based session lifecycle management
- Integration with engram bead tracking system
- Async session archiving via agm-reaper daemon
- See: [claude-session-manager/README.md](claude-session-manager/README.md)

**Note**: workspace-manager has been deprecated in favor of AGM.

## Installation

Each tool has its own installation instructions. See individual tool READMEs.

## Relationship to Engram

These tools are developed alongside [Engram](https://github.com/vbonnet/engram), but are:
- **Independent**: Work without Engram
- **Generic**: Not Engram-specific (except where noted)
- **Experimental**: Alpha quality, use at your own risk
