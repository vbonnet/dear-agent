# Gemini Deep Research - Go Edition

Automatically extract content from web sources (YouTube videos, arXiv papers, HuggingFace papers, and web articles), analyze them with Gemini to identify research topics, and run Deep Research using the Gemini Deep Research API.

## Overview

This tool provides an end-to-end pipeline for automated research:

1. **Content Detection**: Automatically detect content type from URL
2. **Content Extraction**: Extract content using specialized extractors
3. **Topic Analysis**: Use Gemini to identify key research topics
4. **Deep Research**: Run comprehensive research using Gemini Deep Research API
5. **Output Generation**: Generate structured reports and metadata

**Supported Content Types**:
- YouTube videos (requires yt-dlp)
- arXiv papers (PDF or API-based extraction)
- HuggingFace papers
- Generic web articles (using readability)

## Installation

### Prerequisites

1. **Go 1.21 or higher**
   ```bash
   go version  # Should be 1.21+
   ```

2. **Gemini CLI** (for topic analysis)
   ```bash
   # Installation instructions
   # See: https://github.com/google/generative-ai-cli

   # Verify installation
   gemini --version
   ```

3. **yt-dlp** (optional, for YouTube videos)
   ```bash
   pip install yt-dlp

   # Verify
   yt-dlp --version
   ```

4. **Gemini API Key**
   ```bash
   export GEMINI_API_KEY="your-api-key-here"
   ```
   Get your API key from: https://ai.google.dev/

### Build from Source

```bash
# Clone repository
git clone https://github.com/vbonnet/ai-tools
cd ai-tools/tools/gemini-deep-research

# Build
go build -o gemini-deep-research

# Install globally (optional)
sudo mv gemini-deep-research /usr/local/bin/
```

### Install via Go

```bash
go install github.com/vbonnet/ai-tools/tools/gemini-deep-research@latest
```

## Quick Start

### Basic Usage

```bash
# Analyze a YouTube video
gemini-deep-research https://www.youtube.com/watch?v=VIDEO_ID

# Analyze an arXiv paper
gemini-deep-research https://arxiv.org/abs/2501.12345

# Analyze a HuggingFace paper
gemini-deep-research https://huggingface.co/papers/2501.12345

# Analyze a web article
gemini-deep-research https://example.com/article
```

### With Custom Prompt

```bash
# Short prompt
gemini-deep-research --input "Focus on security topics" https://example.com

# Prompt from file
gemini-deep-research --input-file ./prompts/security.txt https://example.com
```

### With Configuration

```bash
# Custom output directory
gemini-deep-research --output-dir ./research https://example.com

# Custom timeout (in minutes)
gemini-deep-research --timeout 90 https://example.com

# Specify GCP project
gemini-deep-research --project my-project-id https://example.com

# Override content type detection
gemini-deep-research --type article https://youtu.be/VIDEO_ID
```

## Configuration

### Command-Line Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--input <text>` | Short custom prompt for topic analysis | None |
| `--input-file <path>` | Path to file containing custom prompt | None |
| `--type <type>` | Override content type (video\|article\|arxiv\|huggingface) | Auto-detect |
| `--output-dir <path>` | Output directory for results | `./output` |
| `--timeout <minutes>` | Deep Research timeout in minutes | 60 |
| `--project <id>` | GCP project ID | From env |
| `--help, -h` | Show help message | - |
| `--version, -v` | Show version | - |

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `GEMINI_API_KEY` | API key for Deep Research | **Required** |
| `GOOGLE_CLOUD_PROJECT` | GCP project ID | None |
| `GEMINI_DR_OUTPUT_DIR` | Default output directory | `./output` |
| `GEMINI_DR_TIMEOUT` | Research timeout (minutes) | 60 |

### Configuration Priority

1. Command-line flags (highest priority)
2. Environment variables
3. Default values (lowest priority)

## Output Structure

Each run creates a timestamped directory:

```
output/
└── 20240203-150405-example-com/
    ├── metadata.json      # Run metadata (URL, topics, timestamp)
    ├── topics.json        # Identified topics list
    ├── report.md          # Deep Research report (Markdown)
    └── content.txt        # Extracted content (for reference)
```

### metadata.json

```json
{
  "url": "https://example.com/article",
  "content_type": "GenericArticle",
  "topics": ["Topic 1", "Topic 2", "Topic 3"],
  "timestamp": "2024-02-03T15:04:05Z",
  "metadata": {
    "title": "Article Title",
    "authors": ["Author Name"]
  }
}
```

### topics.json

```json
{
  "topics": [
    "Topic 1",
    "Topic 2",
    "Topic 3"
  ]
}
```

### report.md

Comprehensive research report in Markdown format, generated by Gemini Deep Research.

## Troubleshooting

### Error: "gemini CLI not found"

**Solution**: Install Gemini CLI
```bash
# See: https://github.com/google/generative-ai-cli
```

### Error: "GEMINI_API_KEY not set"

**Solution**: Set API key
```bash
export GEMINI_API_KEY="your-api-key-here"
```

Get your key from: https://ai.google.dev/

### Error: "yt-dlp not found"

**Solution**: Install yt-dlp (only needed for YouTube videos)
```bash
pip install yt-dlp
```

### Error: "Failed to extract transcript from video"

**Possible causes**:
1. Video has no subtitles → Try different video
2. Video is private/restricted → Use public video
3. yt-dlp needs update → Run `pip install --upgrade yt-dlp`

### Error: "Deep Research timeout"

**Solution**: Increase timeout
```bash
gemini-deep-research --timeout 120 https://example.com
```

### Error: "Rate limit exceeded"

**Solution**: Wait and retry. The tool includes automatic retry with exponential backoff.
