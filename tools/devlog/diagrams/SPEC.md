# Devlog Diagram Rendering Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**DEVLOG-DIAGRAM-01** When devlog diagrams are rendered, the system shall generate outputs from the checked-in diagram sources.

**DEVLOG-DIAGRAM-02** If rendering fails, the system shall retain the previous valid artifact and return a failing status.
