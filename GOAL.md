# dear-agent direction

Project purpose is defined by
[`docs/alignment/MISSION.md`](docs/alignment/MISSION.md), which is canonical for
the VROOM/AGM ownership boundary.

Use the supporting alignment documents for distinct questions:

- [`VISION.md`](docs/alignment/VISION.md) describes the desired future.
- [`GOALS.md`](docs/alignment/GOALS.md) lists qualitative outcomes to improve.
- [`VALUES.md`](docs/alignment/VALUES.md) records non-ranked decision constraints.
- [`CONTEXT.md`](CONTEXT.md) owns repository vocabulary and framework relationships.

This pointer intentionally contains no second definition of the project's
purpose.
