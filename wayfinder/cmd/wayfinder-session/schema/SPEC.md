# Wayfinder Session Schema Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**DECL-WF-SCHEMA-01** When Wayfinder validates project or phase state, the system shall use the versioned canonical schema and examples.

**DECL-WF-SCHEMA-02** If persisted session state violates the canonical schema, the system shall reject the invalid state with diagnostics.
