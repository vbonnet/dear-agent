# Wayfinder Shell Library Specification

<!-- Last audited at: 2026-07-10 -->

## EARS Requirements

**WF-SHELL-LIB-01** When a Wayfinder shell gate evaluates a phase transition, the system shall enforce the canonical V2 phase and deliverable requirements.

**WF-SHELL-LIB-02** When Wayfinder spawns or monitors delegated work, the system shall preserve task identity and propagate unsuccessful worker outcomes.
